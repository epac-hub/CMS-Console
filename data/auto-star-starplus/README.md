## Key finding: where the full help files live

The complete Star-Plus user manuals, release notes, and knowledge base articles are **login-gated**:

1. **Auto-Star Knowledgebase wiki** — https://wiki.auto-star.com/ (release notes at `wiki?topic=456`). Account requests are processed in 2–3 business days.
2. **Customer login** — https://www.auto-star.com/login/ (product manuals, release notes, approved hardware, webinars, downloads).
3. **In-software**: Star-Plus 8.4+ ships **HelpBot**, an AI assistant that searches the full documentation library (user manuals / release notes / table documents) from inside the POS; access is controlled by the Trust Level Editor.
4. **Support line**: (888) 460-6963 option 1, Mon–Fri 7:00–16:30 MST (24/7 emergency).
